## 详细描述（≤ 10,000 字符）

```
B站专注模式（非官方）· Bilibili Focus

看网课的时候，推荐视频、广告、评论、花里胡哨的导航栏总在抢注意力。这个扩展在视频页右下角放一个按钮，点一下，页面只剩标题、播放器和视频选集。

【一键专注】
· 点右下角按钮，或按 Alt + Z
· 隐藏：顶部导航、右侧 UP 主卡片、相关推荐、广告位、评论区、视频标签、右侧悬浮按钮
· 保留：视频标题、播放器、视频选集（分 P 列表）、视频简介、弹幕开关
· 再点一下立刻恢复，不需要刷新页面

【点选删除】
看到还想删的东西？点「点选删除页面元素」，鼠标移到目标上会出现蓝色高亮框，单击即可隐藏，并记入列表；按 Esc 退出。列表里点 × 可以单独恢复某一项。

【按需定制】
齿轮面板里可以逐项开关 10 类模块，还能开启「宽屏播放器」，把右侧栏收起来让播放器铺满窗口。设置会记住。

【为什么不是直接删 DOM】
B 站是单页应用，切分 P、加载评论都会重新挂载节点，直接删掉的元素会「长回来」。本扩展用 CSS 隐藏，稳定且随时可逆。

【隐私】
· 不联网、不上传、不读取账号信息
· 只在本机 localStorage 里保存开关状态和自定义选择
· 无统计、无广告、无远程代码
· 仅在 *.bilibili.com 页面运行

【说明】
本扩展为非官方工具，与哔哩哔哩无关联。它只把已经渲染出来的页面区块隐藏，不下载视频、不绕过会员或清晰度限制、不拦截广告请求。B 站改版可能导致个别区块失效，届时可用「点选删除」手动处理。
```

## 权限用途说明（Permission justification）

如果表单里问 "Why do you need these permissions?"，粘贴：

```
本扩展在 manifest 中没有声明任何 chrome.* 权限（无 permissions 字段），只声明了一个内容脚本，匹配范围是 *://*.bilibili.com/*。

用途：
1) 在 B 站视频页右下角渲染一个悬浮开关按钮；
2) 根据用户的选择，给 <html> 添加 class，用 CSS 的 display:none 隐藏推荐、广告、评论等区块；
3) 用 localStorage 保存开关状态与用户点选的选择器。

不读取账号、Cookie 或观看记录，不发起任何网络请求，不访问其他网站，不加载远程代码。
```

## Notes for certification（给审核员的测试说明）

```
测试步骤（无需登录、无需特殊账号）：

1. 安装扩展后打开 https://www.bilibili.com/video/BV1C8DUY5EBf/
2. 页面右下角出现「专注模式」按钮（若未出现，刷新一次页面）
3. 点击按钮：顶部导航、右侧推荐、广告、评论区、标签会被隐藏，视频选集保留
4. 再次点击按钮或按 Alt+Z：页面完全恢复
5. 点击齿轮：可逐项开关 10 类模块，可开启「宽屏播放器」
6. 点击「点选删除页面元素」：鼠标悬停出现蓝色高亮框，单击隐藏该元素，Esc 退出

说明：
· 站点为中文，扩展界面也是中文；
· 扩展不联网，所有逻辑在本地执行；
· 不修改任何网络请求，只是隐藏已渲染的页面区块。
```
