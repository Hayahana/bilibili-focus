# B站专注模式 · Bilibili Focus

一个给 Edge / Chrome 用的浏览器扩展：在 B 站视频页右下角放一个按钮，**点一下就把推荐、广告、评论、顶部导航全部藏起来**，只留下课程标题、播放器和选集，方便一口气刷完一门课。

纯前端 `display: none`，不删节点、不改请求、不碰账号，随时一键还原。

---

## 一、可行性结论

| 需求 | 做法 | 是否可行 |
| --- | --- | --- |
| 一个按钮，一键去掉无关内容 | content script 注入悬浮按钮 + 给 `<html>` 加 class，CSS 按 class 批量隐藏 | ✅ 完全可行 |
| 删掉 `.rec-list` / `#biliMainHeader` 这类区块 | 按选择器 `display:none !important` | ✅ 已经内置 |
| 页面重新渲染后仍然生效 | 用 class + CSS，而不是真的 `remove()` 节点 | ✅ 切 P、翻页都不会“复活” |
| 想删哪个就点哪个 | 点选模式：鼠标指到哪高亮哪，点一下生成选择器并隐藏 | ✅ 已实现 |
| 刷新后记住状态 | `localStorage`，并在首屏渲染前生效（不会闪一下） | ✅ 已实现 |

> 为什么不直接 `element.remove()`：B 站是 Vue 单页应用，切分 P / 加载评论时会重新挂载节点，删掉的 DOM 会“长回来”；而且删错了只能刷新。CSS 隐藏既稳又可逆。

## 二、安装（Edge，约 1 分钟）

1. 把 `bilibili-focus` 文件夹解压到任意固定位置（例如 `D:\Extensions\bilibili-focus`），**不要**放在临时目录，扩展运行时会一直读这个文件夹。
2. 打开 `edge://extensions/`。
3. 打开左下角的 **开发人员模式**。
4. 点 **加载解压缩的扩展**，选择 `bilibili-focus` 文件夹（里面能直接看到 `manifest.json` 的那一层）。
5. 打开任意 B 站视频页，右下角会出现「专注模式」按钮。

Chrome 同理：`chrome://extensions/` → 打开「开发者模式」→「加载已解压的扩展程序」。

## 三、怎么用

- **点右下角「专注模式」**：一键开关。开启后按钮变蓝、显示「专注中」。
- **快捷键 `Alt + Z`**：不用找按钮，随时开关。
- **点扩展工具栏图标**：同样可以开关当前标签页（需要页面已加载扩展）。
- **齿轮 ⚙**：逐项选择要隐藏什么，默认已经勾好最常用的几项。
- **点选删除页面元素**：
  1. 点「点选删除页面元素」；
  2. 鼠标移到想去掉的地方，会出现蓝色高亮框和选择器提示；
  3. 点一下，立刻消失，并记进列表；
  4. `Esc` 退出点选模式。
  5. 在齿轮面板的列表里点 `×` 可以单独恢复某个元素。

### 默认隐藏 / 默认保留

| 默认隐藏 | 默认保留 |
| --- | --- |
| 顶部导航、搜索栏 | 视频标题、UP 主名 |
| 右侧 UP 主卡片、相关推荐、推荐流 | **视频选集（26 讲的分 P 列表）** |
| 所有广告位（左侧横幅、右下角、贴片） | 播放器、进度条、清晰度 |
| 评论区 | 视频简介（常有课件 / 资料链接） |
| 视频标签、右侧悬浮按钮 | 弹幕开关、倍速 |

「宽屏播放器」是**可选**的：勾上之后右栏（连选集一起）让位，播放器按 16:9 铺满窗口。看单集、想沉浸时再开。

## 六、想自己加规则

打开 `src/focus.css`，照抄一行即可，例如连「视频选集」也不想要：

```css
html.bfm-on.bfm-h-pod .video-pod { display: none !important; }
```

已有规则都遵循同一个约定：`html.bfm-on`（总开关）+ `bfm-h-xxx`（分项）。改完在 `edge://extensions/` 点一下扩展卡片上的「重新加载」，刷新页面生效。

B 站改版后某个选择器失效，也可以不改代码——直接用「点选删除」点掉它，规则存在浏览器里。

## 七、边界与说明

- **只在本地生效**：不联网、不上传、不读取账号信息；扩展只申请了 B 站站点的内容脚本权限，没有 `storage`、`tabs` 等额外权限。
- **播放器内部点不到**：B 站播放器是 Shadow DOM / 独立组件，点选模式只能选到播放器外壳；播放器里的推荐、结束页广告由播放器自己控制，不在本扩展范围内。
- **不绕过任何限制**：不下载、不解锁清晰度、不去广告请求，只是把已经渲染出来的区块藏起来。
- **状态存在 `localStorage`**：清理浏览器站点数据会重置为默认（关闭）。
- 如果某天 B 站大改版导致某些区块藏不掉，用「点选删除」补一刀即可。
